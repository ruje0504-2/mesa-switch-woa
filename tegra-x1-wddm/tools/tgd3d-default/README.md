# .158 + tgd3d 开机自动启用包

本包保留原签名 `.158` KMD 和配套 ARM64 NVK ICD。当前UMD为CPU同步对照版，
双向GPU Fence桥接屏蔽，Vulkan硬件渲染保留。天气/大面积弹层重启尚未修复，
本包用于手动测试，不代表稳定性验收通过。

1. 当前应为已安装的冻结 `.158 / Code43` 桌面，以管理员身份运行 `INSTALL.cmd`。
2. 安装结束后自行重启Windows。登录桌面约5秒后自动启用tgd3d，无需再运行测试命令。
3. 不会自动开测试窗口、采集Dump、回退`.59`或重启Windows。CPU、风扇和睡眠设置保持。

启用期间如果崩溃，下一次登录会保留BasicDisplay并停止重复启用，避免启动循环。
需要恢复时，以管理员身份运行本包的 `RESTORE.cmd`：关闭自动启用、恢复原显示
设置并重启，保留 `.158`，不安装 `.59`。完整组件来源和SHA256见 `trial-components.json`。
