# .158 + tgd3d 开机自动启用包

本包使用清单中指定的 `.158` KMD 和配套 ARM64 NVK ICD；若包含
`kmd_variant: shader-output-bit14`，则在原 `.158` 上只移植 bit14 修复，
并附带原签名 KMD 的恢复文件。当前UMD为CPU同步对照版，
双向GPU Fence桥接屏蔽，Vulkan硬件渲染保留。天气/大面积弹层重启尚未修复，
本包用于手动测试，不代表稳定性验收通过。

1. 当前应为已安装的冻结 `.158 / Code43` 桌面，以管理员身份运行 `INSTALL.cmd`。
2. 安装结束后自行重启Windows。登录桌面约5秒后自动启用tgd3d，无需再运行测试命令。
3. 不会自动开测试窗口、采集Dump、回退`.59`或重启Windows。CPU、风扇和睡眠设置保持。

启用期间如果崩溃，下一次登录会保留BasicDisplay并停止重复启用，避免启动循环。
bit14 包需要恢复时，以管理员身份运行 `RESTORE.cmd`：先关闭自动启用，
如原生 GPU 正在运行，会提示手动重启；重启后再运行一次，恢复原签名 `.158`
并保持启动门控关闭。不会热切换正在运行的 GPU，也不安装 `.59`。
未包含 bit14 的旧包仍使用原显示设置恢复流程。完整组件来源和SHA256见 `trial-components.json`。
